# Publish a self-hostable Apache-2.0 core

The collector, parsers, redaction, encrypted spool, CLI, MCP server, schemas, search, API, worker, and single-tenant web application are licensed under Apache-2.0 so the trust-sensitive product is inspectable and self-hostable. Managed multi-tenant operations, billing, abuse controls, enterprise identity policy, and private production runbooks may remain outside the public repository.
