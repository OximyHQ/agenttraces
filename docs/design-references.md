# Product and interface references

AgentTraces uses references to sharpen hierarchy and interaction, not to copy
their words, assets, or product model.

## givemeanode.com

The public site takes its proportions from the compact, restrained surface at
[givemeanode.com](http://givemeanode.com/): a narrow centered frame, small Inter
type, generous whitespace, plain navigation, thin rules, and compact command
panels. AgentTraces keeps original copy and its own trace-first information
architecture. `DESIGN.md` is the implementation contract.

## traces.com

The supplied traces.com screenshots are the reference for a trace that feels
native rather than log-like: provider identity is immediately scannable, tool
operations have distinct semantics, and the public trace itself is the product
surface. AgentTraces deliberately keeps only two trace modes—Overview and Full
trace—and gives public links a readable title slug plus an opaque capability
token.

## Review checklist

- Source and model-provider marks appear beside written labels where useful.
- Commands, searches, file changes, web calls, tests, and sub-agents remain
  semantically distinguishable in the full trace.
- Public-share metadata clearly says immutable snapshot or live share.
- The readable share slug is descriptive only; authorization never depends on it.
- Synthetic dashboard data is visibly labeled as a preview.
