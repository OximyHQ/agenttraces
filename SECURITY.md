# Security

AgentTraces reads local coding-agent artifacts, so security and privacy reports receive priority.

Please do not open a public issue for a suspected vulnerability. Email `security@oximy.com` with a description, reproduction steps, affected versions, and any suggested mitigation. We will acknowledge a complete report within five business days and coordinate disclosure after a fix is available.

Never include real trace contents, credentials, customer data, or private repository material in a report. Use synthetic fixtures whenever possible.

The currently supported security-update line is the latest published `agenttraces` npm version and the `master` branch.
